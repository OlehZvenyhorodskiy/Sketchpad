# System Requirements for Sketchpad (MeCanvas v2.0.0)

## 1. Windows PC (Desktop Version)

### Minimum Requirements:
- **Operating System**: Windows 10 64-bit (Build 19041+) or Windows 11
- **Processor**: Intel Core i3 (6th Gen+) or AMD Ryzen 3 (Quad-Core, 2.0 GHz+)
- **Memory (RAM)**: 4 GB RAM
- **Graphics**: GPU with OpenGL 3.3+ / DirectX 11 support (for Skiko acceleration)
- **Disk Space**: 350 MB free disk space (portable standalone bundle)
- **Display**: $1280 \times 720$ resolution
- **Java Runtime**: None required! (Bundled self-contained OpenJDK 21 LTS runtime included)

### Recommended Requirements:
- **Processor**: Intel Core i5/i7 (10th Gen+) or AMD Ryzen 5/7
- **Memory (RAM)**: 8 GB+ RAM
- **Graphics**: Dedicated GPU (NVIDIA GTX 1050+ / AMD Radeon RX 560+ / Intel Iris Xe)
- **Display**: $1920 \times 1080$ or $4\text{K}$ high-DPI monitor with 100%+ scaling support
- **Digitizer/Input**: Wacom, Huion, XP-Pen graphic tablet, or Microsoft Surface Pen (Windows Ink API compatible)

---

## 2. Android Tablet (Mobile Version)

### Minimum Requirements:
- **Operating System**: Android 8.0 (API Level 26 - Oreo) or higher
- **Target OS**: Android 14 / 15 (API Level 34 / 35)
- **Processor**: Octa-Core 1.8 GHz ARM64 (e.g. Snapdragon 680, MediaTek Helio G88)
- **Memory (RAM)**: 3 GB RAM
- **Storage**: 100 MB free internal storage
- **Display**: 8.0-inch tablet screen ($1280 \times 800$ minimum)

### Recommended Requirements:
- **Device Form Factor**: 10.5" to 14.6" Tablet (Samsung Galaxy Tab S7/S8/S9 series, Xiaomi Pad 6, Lenovo Tab P11/P12, Pixel Tablet)
- **Stylus**: Active Pen (Samsung S-Pen, Xiaomi Smart Pen, Lenovo Precision Pen) with pressure sensitivity (4096 levels) and tilt support
- **Refresh Rate**: 90 Hz or 120 Hz AMOLED / IPS display for ultra-low stylus latency
- **Network**: 5 GHz 802.11ac/ax Wi-Fi network (or USB Type-C tethering) for low-latency SketchLink streaming ($< 16\text{ ms}$)
