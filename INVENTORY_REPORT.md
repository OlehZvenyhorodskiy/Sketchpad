## 2. DRAWABLE TOOLS (з `app/src/main/java/com/example/brush/` та `core/drawing/`)

### 2.1 Перелік інструментів (`ToolType`):
1. **`PEN`** — Тонке гладке перо для записів і креслення.
2. **`PENCIL`** — Олівець з імітацією графітового тертя, текстурним jitter та підтримкою нахилу.
3. **`INK_PEN`** — Чорнильне перо з ефектом накопичення фарби при повільному русі (`flow = 0.8`).
4. **`FOUNTAIN_PEN`** — Каліграфічне перо зі зрізаним кінчиком для каліграфічного письма.
5. **`MARKER`** — Напівпрозорий маркер/текстовиділювач (`opacity = 0.38`, плоскі кінці).
6. **`AIRBRUSH`** — Аерограф з розсіюванням точок (`scatter = 8f`, `jitter = 3f`).
7. **`CRAYON`** — Воскова крейда з зернистою текстурою.
8. **`WATERCOLOR_BRUSH`** — Акварельний художній пензель.
9. **`LASER`** — Лазерна указка з анімацією згасання (для демонстрацій).
10. **`POINTER`** — Курсор-вказівник для взаємодії з елементами.
11. **`SELECTOR`** — Інструмент виділення (Lasso / Прямокутний Box) з переміщенням, масштабуванням, обертанням і копіюванням.
12. **`ERASER`** — Векторний розумний ластик:
    - *Object Eraser*: миттєве стирання цілого штриха при перетині.
    - *Pixel Eraser*: точне геометричне розрізання векторних сплайнів по радіусу ластика зі спрощенням Ramer-Douglas-Peucker (RDP).
13. **`FILL`** — Заливка замкнених областей кольором.
14. **`EYEDROPPER`** — Піпетка для зчитування кольору з будь-якої точки полотна.
15. **`RULER`** — Лінійка, транспортир, циркуль з магнітним прилипанням.
16. **`TEXT`** — Текстові блоки з форматуванням і шрифтами.
17. **`PIXEL`** — Піксель-арт режим з дискретною сіткою.

### 2.2 Вбудовані пресети пензлів (`BrushPresets.kt`):
- `pen_fine` (Тонке перо, 2px, EaseInOut)
- `pen_medium` (Середнє перо, 4px, Linear)
- `pencil_hb` (Олівець HB, 3px, Light curve, Jitter 0.3)
- `pencil_2b` (Олівець 2B, 5px, Heavy curve, Jitter 0.5)
- `marker_wide` (Маркер, 12px, Opacity 0.38)
- `calligraphy` (Каліграфія, 6px, EaseIn)
- `ink_brush` (Чорнильний пензель, 8px, Flow 0.8)
- `spray` (Спрей, 20px, Scatter 8, Jitter 3)
- `dashed` (Пунктир, 3px, Pattern 12/8)

## 3. ТЕМИ ТА СТИЛІ (з `app/src/main/java/com/example/ui/theme/`)

Повна підтримка 10 стилів оформлення з `ThemeSpec.kt` та неоморфізму `NeumorphicModifier.kt`:

1. **`SYSTEM_DEFAULT`** — Світла/Темна Material 3 адаптивна тема з акцентом `#38BDF8`.
2. **`PAPER_NOTEBOOK`** — Текстура бежевого блокнота (`#F5F1E8`, `#8C6D46`, радіус 8dp).
3. **`NEUMORPHISM`** — М'який подвійний тіньовий неоморфізм (`#E0E5EC` / `#242830`, подвійні тіні -4dp/+4dp).
4. **`AMOLED_BLACK`** — Справжній глибокий чорний (`#000000`) для максимального контрасту.
5. **`CHALKBOARD`** — Стиль шкільної зеленої дошки (`#1B3A2F`) з крейдяними акцентами (`#FACC15`).
6. **`SEPIA_EINK`** — Сепія-режим для читання/малювання електронного паперу (`#EDE4D3`, `#4A3F35`).
7. **`MIDNIGHT_INDIGO`** — Глибокий нічний синій (`#0D1020`, `#151A32`, `#AFC6FF`).
8. **`FOREST_STUDY`** — Природний лісовий зелений стиль (`#F5F8F1`, `#166534`).
9. **`ROSE_QUARTZ`** — Пастельний кварцовий/рожевий стиль (`#FFF7FA`, `#9D174D`).
10. **`HIGH_CONTRAST`** — Режим надвисокого контрасту для доступності (WCAG AAA).

## 4. АКАДЕМІЧНІ ІНСТРУМЕНТИ (з `app/src/main/java/com/example/academic/`)

1. **`FunctionPlotterEngine.kt`:**
   - Поліноміальна апроксимація 2-го порядку ($y = ax^2 + bx + c$).
   - Розрахунок коефіцієнта детермінації $R^2$.
   - Генерація згладжених точок графіка та LaTeX формули.
2. **`ShapeRecognizerEngine.kt`:**
   - Геометричний аналіз рукописних ліній: кола, трикутники, прямокутники/квадрати.
   - Алгоритм Ramer-Douglas-Peucker (RDP) для пошуку вершин.
3. **`MathExpressionEvaluator.kt`:**
   - Парсер математичних виразів у зворотну польську нотацію (Shunting-yard algorithm).
   - Підтримка функцій: $\sin, \cos, \tan, \cot, \sqrt{}, \ln, \log, \exp, \text{abs}, \text{asin}, \text{acos}, \text{atan}$, констант $\pi, e$, степенів $x^y$, неявного множення.
4. **`HandwritingLatexConverter.kt`:**
   - Heuristic / AI перетворення штрихів на інтеграли, дроби, суми, рівняння.
5. **`SmartLectureRecorder.kt`:**
   - Прив'язка кожного штриха (`StrokePoint.timestampMs`) до аудіодоріжки лекції.
6. **`LocalCodeAnalyzer.kt`:**
   - Локальний інтерпретатор та валідатор коду Python, C, C++ без зовнішніх залежностей.
7. **`SpacedRepetitionScheduler.kt`:**
   - Математична реалізація алгоритму інтервального повторення SuperMemo-2 (SM-2).

## 5. AI КОМПОНЕНТИ (з `app/src/main/java/com/example/ai/`)

1. **`AiProvider.kt` & `AiProviderRegistry`:**
   - `GeminiProvider`: REST клієнт Google Gemini API (Multimodal Vision + Text).
   - `OpenAiProvider`: REST клієнт OpenAI (GPT-4o, GPT-4o-mini).
   - `AnthropicProvider`: REST клієнт Claude 3.5 Sonnet.
   - `DeepSeekProvider`: REST клієнт DeepSeek R1 / V3.
   - `CustomOpenAiCompatibleProvider`: Будь-який локальний або хмарний сервер (Ollama, LM Studio, vLLM).
2. **`GeminiAssistantService.kt`:**
   - Потоковий чат з історією повідомлень, генерація підсумків нотаток, створення тестів.
3. **`HandwritingOcrService.kt` & `LatexAutoCompleter.kt`:**
   - Розпізнавання рукописного тексту та формул з виділеної області.

## 6. ІНШІ МОДУЛІ (Data, Audio, Drive, Localization)

- **`audio/AudioRecorderManager.kt`:** Запис через системне аудіо, вимірювання амплітуди, збереження у WAV/AAC/MP3.
- **`data/storage/AtomicCanvasStorage.kt`:** Атомарний файловий запис проектів зі створенням резервних копій `.bak` для запобігання втраті даних.
- **`drive/ExportManager.kt`:** Експорт у PNG (растровий з OOM-захистом), SVG (чистий вектор), PDF (багатосторінковий документ), Obsidian Vault (Markdown з frontmatter).
- **`localization/AppLanguage.kt`:** Локалізація на 5 мов: Англійська (EN), Українська (UK), Нідерландська (NL), Німецька (DE), Французька (FR).
